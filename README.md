# 抖音网页版直播弹幕关键词屏蔽插件

这是一个基于 Chrome Manifest V3 的浏览器插件示例，用于在抖音网页版直播页面按关键词屏蔽弹幕。

## 功能

- 支持在弹窗中自定义屏蔽词（每行一个）。
- 关键词保存在 `chrome.storage.sync`，浏览器同步账号下可复用。
- 在抖音直播页面实时监听新增弹幕，并自动隐藏匹配内容。

## 文件结构

- `manifest.json`：插件清单。
- `content.js`：注入抖音直播页面，执行弹幕过滤逻辑。
- `popup.html` / `popup.css` / `popup.js`：设置屏蔽词的 UI 和存储逻辑。

## 使用方式

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 打开 `https://live.douyin.com/` 任意直播间。
6. 点击扩展图标，在弹窗中输入关键词并保存。

## 说明

- 页面 DOM 结构可能会变动；如抖音改版，可在 `content.js` 中调整弹幕节点选择器。
- 当前策略是“包含关键词即隐藏”，不区分大小写。
