# 抖音网页版直播弹幕关键词屏蔽插件

这是一个基于 Chrome Manifest V3 的浏览器插件，用于在抖音网页版直播间中自动屏蔽包含指定关键词的弹幕。

## 功能

- 支持在插件弹窗中自定义屏蔽词。
- 支持多种分隔方式：换行、中文/英文逗号、分号。
- 监听页面动态更新，尽量实时屏蔽新出现的弹幕。
- 屏蔽词保存到 `chrome.storage.sync`，可随账号同步（取决于浏览器设置）。

## 目录结构

```text
./douyin-danmu-filter
├── manifest.json

├── popup.css
└── popup.js
```

## 安装方式（开发者模式）

1. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本仓库中的 `douyin-danmu-filter` 文件夹。

## 使用方法

1. 打开抖音网页版直播页面（如 `https://live.douyin.com/...`）。
2. 点击浏览器扩展栏中的「抖音直播弹幕关键词屏蔽」。
3. 在输入框中填入要屏蔽的关键词（每行一个，或逗号分隔）。
4. 点击「保存」，页面中的新老弹幕会按关键词进行隐藏。

## 注意事项

- 抖音页面结构可能变化，若未来弹幕节点 class/data 属性调整，可能需要更新 `content.js` 中的选择器。
- 本插件通过隐藏命中的弹幕元素实现过滤，不会修改服务器数据。
